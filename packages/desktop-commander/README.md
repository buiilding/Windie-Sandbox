# Desktop Commander

Desktop Commander is a local MCP server for filesystem and process operations.

This Windie package contains a pinned MCPB release of Desktop Commander
`0.2.47`. Windie installs the bundle, supplies an isolated HOME, writes the
Windie configuration, starts the server over stdio, and removes the complete
plugin directory during uninstall.

The upstream project is available at
https://github.com/wonderwhy-er/DesktopCommanderMCP.
