# Chrome DevTools

Chrome DevTools lets Windie inspect, debug, and automate a separate persistent Chrome browser profile.

## What it provides

The provider exposes browser pages, debugging, and automation tools through MCP.

## Setup

Windie creates a separate browser profile. Log into websites in that profile once when needed; Windie reuses that profile later.

## Safety

The normal Chrome profile and its open tabs are not used. Browser tools can access websites and perform actions, so use approval mode when reviewing automation.
