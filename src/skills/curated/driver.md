# Windie computer driver

Use the computer driver only for the specific user-requested interaction.

1. Read the current task and identify the exact visible application or page.
2. Inspect the current state before taking an action.
3. Prefer the smallest reversible action that advances the task.
4. Do not submit forms, send messages, purchase anything, delete data, or
   change account settings without explicit user authorization.
5. After an action, inspect the result and report failures instead of guessing.

The Windie runtime controls which computer-control tools are available and
which calls require approval.
