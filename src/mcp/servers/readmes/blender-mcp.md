# Blender MCP

Blender MCP lets Windie inspect and control a local Blender instance.

## What it provides

The provider exposes Blender scene and creative-workflow tools through MCP.

## Requirements

- Blender MCP and its `uv` runtime.
- Blender running with the MCP bridge enabled.

## Safety

Blender tools can modify the open project. Review tool calls before allowing changes to scenes or files.
