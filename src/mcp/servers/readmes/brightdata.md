# Bright Data

Bright Data lets Windie search and access live web data through a hosted MCP provider.

## Requirements

- A Bright Data API token.
- Network access.

## Setup

Enter the token in Windie’s provider settings. Windie stores it in its local environment file and does not expose the secret to the model.

## Safety

Requests use the network and may access external websites. Review network-enabled tools before attaching them to a conversation.
