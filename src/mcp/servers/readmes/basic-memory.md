# Basic Memory

Basic Memory gives Windie a local project for storing and searching user-controlled notes and memory.

## What it provides

The provider exposes memory tools backed by Windie’s isolated Basic Memory project.

## Requirements

- Basic Memory and its `uv` runtime.
- Windie creates and owns the isolated project directory.

## Privacy

Windie does not attach other Basic Memory projects to this provider. Only the Windie-owned memory project is in scope.
